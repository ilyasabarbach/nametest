# UI Direction

The current UI direction is "celestial social game" rather than flat casual UI.

## Existing Style Choices

- dark blue space-like backgrounds
- warm gold and coral highlight colors
- serif typography for a dramatic tone
- glowing circles and particles instead of realistic art
- glassy overlay panels for menus and results

## What The UI Is Trying To Feel Like

- playful
- dramatic
- a little mystical
- mobile-friendly
- screenshot-friendly

## Current Strengths

- clear central fantasy
- result screens feel more branded than generic
- share cards match the in-game tone

## Weak Areas Still To Improve

- more polished transitions between scenes
- stronger motion hierarchy
- richer sound design
- more deliberate spacing and scaling on large desktop screens

## Rule Of Thumb

If a UI change makes the game feel more like a generic form app, it is probably the wrong direction.
