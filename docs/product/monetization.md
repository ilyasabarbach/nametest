# Monetization Notes

Real monetization is intentionally deferred right now.

## Current State

The project has a simulated reward flow only.

That means:

- the secret-reading path exists
- the browser ad adapter always grants the reward
- no real ad provider is connected yet

## Why This Is Okay For Now

The current priority is local gameplay quality.

Before integrating real ads, we want to prove:

- the test loop is fun
- the reward flow feels worth using
- the share/result experience is strong

## Future Direction

When monetization is resumed, the intended order is:

1. rewarded ad integration
2. interstitial pacing tuning
3. analytics around conversion and drop-off
4. remote-config tuning of reward thresholds and ad cadence

## Rule To Preserve

Do not let monetization make the early local experience feel worse.

The first session should feel generous and easy to understand.
