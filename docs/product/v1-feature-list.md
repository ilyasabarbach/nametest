# Feature List

This is the practical feature list for the current playable version.

## Implemented

- Responsive full-screen browser game
- Phaser scene flow
- Data-driven test definitions
- Eight current tests in the content manifest
- Multiple scoring formulas
- Daily featured test selection
- Live event rotation
- Name input validation
- Result bands and flavored result variants
- Secret-reading result extension
- Daily rewards
- Reward coins
- Result collections
- Test unlock progression
- Share-card image generation
- Local storage for progress

## Intentionally Deferred

- Real ads SDK
- Real analytics provider
- A/B testing platform
- Native Android publishing pipeline
- Facebook Instant integration
- Live-ops dashboard/tooling

## What Counts As "Done" For Local Testing

The game is considered locally functional when:

- it runs from the root workspace
- the player can play multiple sessions without errors
- progression persists on refresh
- test unlocking works
- share-card generation works
