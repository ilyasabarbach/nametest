# Product Vision

The game is an original, mobile-first social "name test" experience inspired by the feel of old viral Facebook games, but not a literal clone.

## Core Idea

The player types two names, gets a dramatic reading, and feels curious enough to:

- replay with another name
- unlock more tests
- collect more result types
- share an image result with friends

## What Makes This Version Better

The old viral games were often simple and repetitive. This project is trying to improve that by adding:

- a larger catalog of tests
- better result flavoring
- progress and collections
- daily hooks
- event rotation
- branded share cards
- a cleaner technical structure for future platforms

## Current Product Shape

The current local version already supports:

- unlocked and locked tests
- daily featured content
- rotating event flavor
- secret-reading reward flow
- share-card generation
- progression tracking

## Design Principle

Every feature should support at least one of these:

- replayability
- shareability
- progression
- emotional payoff

If a feature does none of those, it is probably low priority.
